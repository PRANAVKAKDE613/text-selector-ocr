# Text Selector OCR (Windows)

A Windows background tool that lets you select any area on the screen
and extract text using OCR — similar to the Screenshot / Snipping Tool,
but for **text copying**.

---

## ✨ Features

- Screenshot-style text selection
- Global hotkey (Ctrl + Caps Lock)
- Runs in the background
- Copies extracted text directly to clipboard
- Supports repeated use
- Offline (uses Tesseract OCR)

---

## 🖥 Requirements

- Windows 10 / 11
- Python 3.10 or newer
- Tesseract OCR
